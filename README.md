# 多 Agent 軟體開發實踐指南

第十週 LLM Wiki 作業的 HTML 自學簡報，共 392 張、79 個閱讀單元。教師可從[交付首頁](https://bowen12274bot.github.io/taica-2026-w010-wiki/)選擇[簡報](https://bowen12274bot.github.io/taica-2026-w010-wiki/slides/book/index.html)、[完整閱讀](https://bowen12274bot.github.io/taica-2026-w010-wiki/slides/book/index.html#contents)、[作業報告與反思](https://bowen12274bot.github.io/taica-2026-w010-wiki/docs/phase2b-final/assignment/index.html)或[Wiki 證據](https://bowen12274bot.github.io/taica-2026-w010-wiki/docs/phase2b-final/assignment/raw-evidence/index.html)。

## 五章閱讀路線

1. Agent 基礎。從模型、工具與執行環境理解一次工程行動。
2. 單 Agent 開發。選擇委託方式與工具，完成修改、複驗及交件。
3. 多 Agent 協作。以角色、Worktree、任務契約與 Task DAG 管理依賴及整合。
4. 多 Agent 工程決策。處理需求歧義、授權、阻塞、衝突與交接。
5. 品質與效率。區分完成回報、驗收證據、成功率、工程成本與長期效益。

使用左右方向鍵或畫面下方按鈕翻頁，以「章節」和「單元」跳讀。「全螢幕」適合投影。「全文閱讀」可查看推導、試次表格與來源，再回到原張。另有[單元索引](https://bowen12274bot.github.io/taica-2026-w010-wiki/docs/phase2b-final/reading-guide.html)與[106 項知識及 490 筆段落對照](https://bowen12274bot.github.io/taica-2026-w010-wiki/docs/phase2b-publish/coverage.html)。
