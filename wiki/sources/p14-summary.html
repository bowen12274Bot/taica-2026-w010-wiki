Git 專案｜原創研究摘要（Codex 整理）｜查閱 2026-11-21

原始來源 https://git-scm.com/docs/git-worktree

日期／版本：2026-09-28（手冊更新於 Git 2.56.0）。對應章節：3、4。

【公開技術文件】 已核對原文：單一 repository 可掛接多個工作目錄，各自檢出適用的分支或提交。工作目錄各有 HEAD 和 index，仍共享物件與多數 refs。可用 git worktree list 查對位置。

適用範圍：各目錄的修改可分開進行，整合仍須檢查 API、資料語義及驗收行為。工作目錄沒有提供程序或服務隔離保證。
