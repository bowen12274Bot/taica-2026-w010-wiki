本章學習目標

依模組邊界、依賴與整合責任選擇角色及工作區。

建議閱讀順序

  1. 專案架構、角色與 Agent 數量
  2. Task DAG 與動態調度
  3. Coordinator、Worker 與 Integrator
  4. Git Worktree 與工作隔離

公開技術來源：P01、P13、P14、P15。

個人研究：U-A（來源回執）。

教學重點

畫出一個介面設計完成後兩項工作才可並行的任務圖；標上誰可交付、誰驗收。

解讀限制

人類團隊理論只能類推；Orca 機制有版本條件，完整自主協調仍缺 trace。

延伸練習

以第二項需求進案為演練：組織生命週期說明哪些角色和基準可沿用，再用分層回報分配資訊與決策權。工作區的介面選擇見工具比較。
