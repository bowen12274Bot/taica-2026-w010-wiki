主要教學路徑

本章學習目標

為一項小改動寫出可執行的完成條件，知道回報應附哪些證據。

建議閱讀順序

  1. 單 Agent 開發流程
  2. Context、Skills 與 MCP
  3. 規格與 Harness Engineering
  4. 工程品質與驗證

公開技術來源：P05、P17。

個人研究：U-A（來源回執）、U-C（來源回執）。

教學重點

以修改輸入驗證為例，請讀者把需求、建置命令與驗收案例各寫一行，再判斷交付是否完整。

解讀限制

Planning Agent 契約只支持設計；他案測試結果有版本與範圍限制。

延伸練習

選同一個修復任務，沿工具比較與工程環境選擇分別觀察模型、工具和人工管理成本，再依資產重用條件判斷應否保存其操作步驟。
