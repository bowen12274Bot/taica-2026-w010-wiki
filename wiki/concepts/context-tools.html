Context、Skills 與 MCP

定義

Context 是本輪可用資訊。團隊可將可重用的操作指引作為 Skill；專案規範則記錄在可被工作工具發現的檔案中。

原理與工程用途

【公開技術文件】 P03 描述 host 透過 client 連接 server，發現可用工具與資源。P05 示範用 AGENTS.md 記錄專案命令。以驗證為例，指引說明要核對哪些條件，工具實際取得測試結果。

適用條件與限制

U01 【歷史研究整理】 區分上下文與工程環境。Skill 在此只作功能性說明，未指定跨產品的載入或權限語義。資源可被發現也不代表可任意操作。

延伸閱讀

Agent Loop 與工具呼叫、規格與 Harness Engineering。

來源：P03、P05、U-A（來源回執）。

【教學編排】 對照操作案例：把正確的規格帶進本輪 Context。
