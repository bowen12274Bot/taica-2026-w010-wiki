Agent Loop 與工具呼叫

定義

一次 run 由準備輸入開始，runner 根據模型輸出的類型分流。

原理與工程用途

【公開技術文件】 有工具請求就由執行環境執行、把結果送回模型；handoff 可轉交其他 Agent，final output 則結束。修程式時可用同一機制讀取測試失敗、修改後重跑。

適用條件與限制

模型能直接給出 final output。工具次數、回答長度與任務驗收是三種不同的量；工程上還須另訂成功條件。
